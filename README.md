# Task Flow Manager

A lightweight React application for managing tasks across four workflow stages: **Backlog**, **Doing**, **Done**, and **Won't Do**. Users can create tasks with a title and description, and organize them using a dropdown-based section selector.

## Features

- Task creation with title and description input
- Default assignment to the Backlog section
- Four workflow sections for task organization:
  - Backlog
  - Doing
  - Done
  - Won't Do
- Dropdown menu for moving tasks between sections
- Clean, responsive UI for intuitive task handling

## Tech Stack

- React
- CSS Modules or Styled Components
- Optional: Context API or Redux for state management
